# 匿名画像共有ツール（ホスト配信型）

無料・自己ホスト型の画像共有ツールです。**ホスト（あなた）が画像を投稿し、匿名の接続者が閲覧のみ**を行います（送信＝配信は限定）。接続者のアクセス状況は、**閲覧者に見える形でプライバシー通知を提示したうえで**、標準的なアクセス解析として記録します。

## できること
- ホストによる画像アップロード・公開・削除（管理トークンで保護）
- 匿名の接続者は閲覧のみ（アップロード・返信不可）
- 接続者の解析ダッシュボード
  - おおよその地域（CDNの国ヘッダ、無ければ言語設定から推定）
  - 機種の種別 / OS / ブラウザ（User-Agentから判定）
  - 通信方法（対応ブラウザのネットワーク・クライアントヒント、接続スキーム）

## プライバシー方針（重要）
- 公開ページに、解析を行う旨のプライバシー通知を常時表示します。
- **IPアドレスそのものは保存しません。** 訪問者数の概算にはHMACで匿名化した短いIDのみを使い、逆引きはできません。
- 個人を特定する目的では使用しません。密かな追跡・特定用途には利用しないでください。
- 正確なキャリア（通信事業者）や住所は取得できません。あくまで「おおよそ」の推定です。

## 使い方
```bash
npm install
ADMIN_TOKEN=your-secret npm start   # 未指定なら起動時にトークンを自動生成・表示
```
- 公開ギャラリー: `http://localhost:3000/`
- ホスト管理: `http://localhost:3000/host?token=<ADMIN_TOKEN>`
- 接続者の解析: 管理画面のリンクから

### 環境変数
| 変数 | 説明 |
| --- | --- |
| `PORT` | 待受ポート（既定 3000） |
| `ADMIN_TOKEN` | ホスト管理トークン。未設定なら毎起動でランダム生成 |
| `ANON_SALT` | 匿名IDハッシュ用ソルト。未設定なら毎起動でランダム生成 |

## テスト
```bash
npm test
```

## 技術構成
- Node.js + Express、テンプレートは EJS、アップロードは multer
- データは `data/*.json`（追記型・依存DBなし）、画像は `uploads/`
